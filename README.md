✧ E'ZOZA — The Art of Becoming

A personal portfolio website with a soft pink aesthetic, falling diamonds
and an interactive intro screen. It tells my story: education, skills,
experience, interests, certificates and projects.
Features

- Animated intro screen with a floating word cloud
- Falling diamonds effect across the whole site
- Smooth scroll-reveal animations
- Animated skill bars
- Filterable projects section (Technology / Creative / Education)
- Responsive design: works on phones, tablets and desktops
- Glassmorphism cards and a sticky navigation bar

## 🛠 Built with

- HTML5
- CSS3 (Grid, Flexbox, animations, backdrop-filter)
- Vanilla JavaScript
- Google Fonts: Playfair Display and DM Sans

## 📁 Project structure

```
├── index.html     # the whole website (HTML, CSS and JS)
├── style.css      # style of my website
└── README.md
```

## 🚀 Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/noname15-cmd/aboutme.git
   ```
2. Open `index.html` in your browser. No installation needed.
